# Spa hotels, Sat 7 – Sun 8 Nov 2026 (from Bedford, max 70 miles)

These are hotels for one night for 2 adults. Each has an indoor pool, and spa or leisure use is included in the room rate. Prices include breakfast, are capped at £350, and come from live Booking.com prices checked on 3 Nov 2026.

- `hotels.csv` lists 64 hotels. 5★ hotels come first, then 4★, cheapest first within each group.
- `airbnb.csv` lists private stays with a hot tub, sauna or pool.
- `rej.csv` lists hotels that were checked and excluded, with the reason.
- `index.html` is the same list as a page you can filter.

The "How sure" column shows how well each hotel's free spa use is backed up:
- **High:** the hotel's own website confirms it.
- **Medium:** booking-site listings or reviews say so.
- **Low:** only Booking.com's automated Q&A says so, so phone the hotel before booking.
